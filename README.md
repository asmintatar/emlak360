# Emlak360

Web tabanli gayrimenkul ilan ve yonetim sistemi.

## Teknolojiler
- Frontend: React + Vite
- Backend: Node.js + Express
- Veritabani: PostgreSQL
- Proje yonetimi: GitHub Projects / Kanban

## Durum
Proje altyapisi hazirlaniyor. Uygulama henuz gelistirilmedi.

## Gelistirme kurallari
- Her gorev GitHub Issue ile takip edilir.
- Ozellikler ayri branch'lerde gelistirilir.
- Degisiklikler Pull Request ile incelenir.
- Test ve DIR kayitlari ilgili gorevle birlikte tutulur.
